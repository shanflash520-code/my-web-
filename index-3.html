✦Tips & Guide

☝ Touch response

Use Accessibility touch options only if they solve a real issue with taps or swipes. Menu names vary by OS version.

🎮 Smooth gameplay

Close resource-heavy apps, keep the device cool, and choose a stable graphics and FPS setting supported by your phone.

⚙ DPI / display size

Smallest width changes interface density, not physical touch sensitivity or game FPS. Record original settings before changing developer options.

Android touch sensitivity

Open Settings and search for Touch sensitivity, Glove mode, or Screen protector mode. Enable only if your phone supports it and it helps with your protector.

iPhone touch settings

Open Settings → Accessibility → Touch. Touch Accommodations can alter how taps and swipes are recognized. It does not increase FPS.

Improve game smoothness

Close heavy background apps, keep storage free, use stable FPS settings, avoid overheating, and keep the screen clean.
